# Scoop bucket for Corresync

Install the local-first Outlook Web CLI and MCP server:

```console
scoop bucket add corresync https://github.com/nkiyohara/scoop-corresync
scoop install corresync/corresync
```

The manifest installs checksummed Windows archives published by
[Corresync](https://github.com/nkiyohara/corresync). It does not require a
Microsoft Graph application or a hosted bridge.
